## 연속 부분 수열 합의 개수

- 문제번호: 131701
- 난이도: Level 2
- 유형: 투 포인터 / 원형 배열 / 해시(Set)

### 문제
자연수로 이루어진 원형 수열(처음과 끝이 연결된 수열)이 주어진다. 이 원형 수열의 연속하는 부분 수열의 합으로 만들 수 있는 **서로 다른 값의 개수**를 반환하는 함수를 완성하라.

(3 ≤ elements 길이 ≤ 1,000, 1 ≤ elements의 원소 ≤ 1,000)

### 입출력 예
| elements | result |
|----------|--------|
| [7,9,1,1,4] | 18 |

### 접근
1. 원형이므로 `elements` 를 그대로 복사한 뒤 뒤에 한 번 더 이어붙여 길이 `2n` 배열 `arr` 를 만든다. 이러면 시작점이 `0..n-1` 어디든, 길이 `1..n` 짜리 연속 구간을 `arr` 안에서 그대로 잘라낼 수 있다.
2. 부분 수열의 **길이** `len` 을 1부터 n까지 바꿔가며:
   - 시작점 `i = 0` 의 윈도우 합을 처음 한 번 직접 더해서 구한다.
   - 이후 시작점을 `1, 2, ..., n-1` 로 옮길 때는 매번 새로 더하지 않고, **슬라이딩 윈도우**로 O(1) 갱신한다: `sum += arr[i+len-1] - arr[i-1]` (뒤에서 원소 하나 들어오고, 앞에서 원소 하나 빠짐).
   - 구한 합을 `set<int>` 에 넣어 자동으로 중복을 제거한다.
3. 모든 `len` 을 다 돌고 나면 `set` 의 크기가 서로 다른 부분합의 개수.

`set` 은 `push_back` 이 아니라 **`insert()`** 로 원소를 추가한다 (정렬된 트리 구조라 "맨 뒤"라는 개념이 없음).

> 주의: `vector` 를 두 배로 이어붙일 때 `arr.insert(arr.end(), elements.begin(), elements.end())` 처럼 **원본을 복사한 별도 벡터**에 붙여야 한다. 자기 자신을 자기 끝에 삽입(`v.insert(v.end(), v.begin(), v.end())`)하는 건 표준상 정의되지 않은 동작(UB).

### 검산 (elements = [7,9,1,1,4])
`arr = [7,9,1,1,4,7,9,1,1,4]`
- len=1: 시작점별 합 → `7,9,1,1,4` (4가지: 1,4,7,9)
- len=2: `16,10,2,5,11` (5가지: 2,5,10,11,16)
- len=3: `17,11,6,12,20` (5가지: 6,11,12,17,20)
- len=4: `18,13,15,21` (4가지: 13,15,18,21)
- len=5: `22` (1가지)

중복 제거 후 총 `18`가지.

### 시간복잡도
O(n²) — 길이(n가지) × 시작점(n가지), 각 갱신은 O(1). `set` 삽입까지 포함하면 O(n² log n).

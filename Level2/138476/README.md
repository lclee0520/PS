## 귤 고르기

- 문제번호: 138476
- 난이도: Level 2
- 유형: 그리디 / 정렬 / 해시

### 문제
경화는 귤 k개를 골라 상자 하나에 담으려 한다. 귤의 크기가 담긴 배열 `tangerine`이 주어질 때, k개를 골랐을 때 크기가 서로 다른 종류의 수의 **최솟값**을 반환하는 함수를 완성하라.

(1 ≤ k ≤ tangerine의 길이 ≤ 100,000, 1 ≤ 크기 ≤ 10,000,000)

### 접근
종류 수를 최소로 하려면 **같은 크기가 많은 것부터** 담으면 된다 (그리디).

1. `unordered_map<int,int> cnt` 로 크기별 개수를 센다. — O(n)
2. 개수 값만 `vector<int> v` 로 옮긴다.
3. `v` 를 **내림차순 정렬** (`sort(v.begin(), v.end(), greater<int>())`).
4. 앞에서부터 개수를 누적하며 종류 수(`answer`)를 1씩 늘리고, 누적합이 `k` 이상이 되는 순간 멈춘다.

가장 개수가 많은 크기부터 순서대로 담으므로, k개를 채우는 데 쓰이는 크기 종류의 수가 최소가 된다.

### 검산 (k = 6, tangerine = [1,3,2,5,4,5,2,3])
크기별 개수: `1→1, 2→2, 3→2, 4→1, 5→2`
내림차순 개수: `[2, 2, 2, 1, 1]`

| 단계 | 더한 개수 | 누적합 | 종류 수 |
|------|-----------|--------|---------|
| 1 | 2 | 2 | 1 |
| 2 | 2 | 4 | 2 |
| 3 | 2 | 6 | 3 → 6 ≥ k, 종료 |

정답 `3`.

### 시간복잡도
O(n log n) — 개수 배열 정렬이 지배적 (해시 집계는 O(n))

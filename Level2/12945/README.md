## 피보나치 수

- 문제번호: 12945
- 난이도: Level 2
- 유형: DP

### 문제
피보나치 수는 F(0) = 0, F(1) = 1이고, 그 이후로는 F(n) = F(n-1) + F(n-2)로 정의된다.
n이 주어질 때 n번째 피보나치 수를 1234567로 나눈 나머지를 반환하는 함수를 완성하라.

(2 ≤ n ≤ 100,000)

### 접근
크기 n짜리 배열 `v`에 `v[k] = F(k+1)`을 저장한다.
- `v[0] = 1` (F(1)), `v[1] = 1` (F(2))
- `i = 2 .. n-1` : `v[i] = (v[i-1] + v[i-2]) % 1234567`
- 답은 `v[n-1] = F(n)`

F(100000)은 `long long` 으로도 오버플로하므로, 더할 때마다 `% 1234567` 을 취해 값을 작게 유지하는 것이 핵심.

### 시간복잡도
O(n) — n까지 한 번 순회, 각 단계 O(1)

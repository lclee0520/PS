## 점프와 순간 이동

- 문제번호: 12980
- 난이도: Level 2
- 유형: 비트 연산 / 그리디

### 문제
0의 위치에서 출발해 n의 위치까지 이동한다. 한 번 이동할 때 건전지를 사용하지 않으면 순간이동(현재 위치 × 2)을 하고, 건전지 1kW를 사용하면 앞으로 1칸(현재 위치 + 1) 이동한다. n에 도착하는 데 필요한 건전지 사용량의 **최솟값**을 반환하는 함수를 완성하라.

(1 ≤ n ≤ 1,000,000,000)

### 접근
0에서 n으로 가는 대신, **n에서 거꾸로 0으로** 간다고 생각한다.

- `n`이 짝수 → 순간이동(×2)으로 도착했을 것이므로 `n /= 2` (건전지 소모 없음)
- `n`이 홀수 → 마지막 한 칸은 건전지를 써서 +1 한 것이므로 `n -= 1` 하고 `answer++`

이 과정을 `n`이 0이 될 때까지 반복하면, 건전지 사용 횟수가 최소가 된다. 순간이동은 공짜이니 가능한 한 많이 쓰고(짝수일 때 나누기), 홀수라 어쩔 수 없을 때만 건전지를 쓰는 그리디.

결과적으로 이 과정은 n을 2진수로 나타냈을 때 **1인 비트의 개수**를 세는 것과 같다 (`__builtin_popcount(n)`으로도 바로 구할 수 있음).

### 검산 (n = 5)
`5(홀,-1)→4(짝,÷2)→2(짝,÷2)→1(홀,-1)→0`
건전지 사용: 5→4, 1→0 두 번 → `answer = 2`. (`5 = 101₂`, 1의 개수 2개와 일치)

### 시간복잡도
O(log n) — n을 절반씩 줄여가며 반복

## JadenCase 문자열 만들기

- 문제번호: 12951
- 난이도: Level 2
- 유형: 문자열

### 문제
문자열 s가 주어질 때, JadenCase(각 단어의 첫 문자만 대문자, 나머지는 소문자)로 바꾼 문자열을 리턴하는 함수를 완성하라.

### 접근
1. 전체 문자열을 `transform` + `::tolower`로 한 번에 소문자로 바꾼다.
2. 문자열의 첫 글자가 알파벳이면 `toupper`로 대문자화한다.
3. 이후 순회하면서 공백(`' '`) 뒤에 알파벳이 오면, 공백은 그대로 넣고 다음 글자를 `toupper`로 대문자화한 뒤 인덱스를 한 칸 더 건너뛴다.

### 시간복잡도
O(n)

### 추가사항
"직전 글자가 공백인가"를 인덱스로 미리 보는 대신, "지금 새 단어의 시작인가"라는 상태(bool)를 들고 한 바퀴만 도는 방식으로 바꾸면:
- 첫 글자를 따로 처리 안 해도 됨
- `s[i+1]` 같은 한 칸 앞선 인덱스 접근이 없음

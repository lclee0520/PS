## 다음 큰 숫자

- 문제번호: 12911
- 난이도: Level 2
- 유형: 비트 연산 / 완전탐색

### 문제
자연수 n이 주어질 때, 다음 조건을 만족하는 "다음 큰 숫자"를 구하는 함수를 완성하라.
- n보다 큰 자연수이다.
- 2진수로 나타냈을 때 1의 개수가 n과 같다.
- 위 두 조건을 만족하는 수 중 가장 작은 수이다.

(1 ≤ n ≤ 1,000,000)

### 접근
`toBeat(x)` : x를 2로 계속 나누면서 나머지(`x % 2`)를 문자열에 모아 2진 표현을 만들고, 그 안의 `'1'` 개수를 반환한다.

`solution` :
1. `number = toBeat(n)` 으로 n의 1의 개수를 구한다.
2. `n + 1` 부터 1씩 증가시키며 각 후보의 1의 개수를 `toBeat` 로 구해, `number` 와 같아지는 첫 수를 찾는다.
3. 조건을 만족하는 순간의 후보 값을 반환한다.

n ≤ 1,000,000 이므로 n+1부터 선형으로 훑어도 충분히 빠르다 (다음 수까지의 간격이 작다).

### 시간복잡도
O(k log n) — 정답까지 확인하는 후보 수 k개 각각에 대해 2진 변환이 O(log n)

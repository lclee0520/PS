## 이진 변환 반복하기

- 문제번호: 70129
- 난이도: Level 2
- 유형: 문자열, 시뮬레이션

### 문제
0과 1로 이루어진 문자열 `s`가 주어진다. `s`가 `"1"`이 될 때까지 다음 과정을 반복한다:
1. `s`에 있는 0을 모두 제거한다.
2. 남은 문자열의 길이(1의 개수)를 2진법으로 표현한 문자열로 `s`를 바꾼다.

반복한 횟수와, 그 과정에서 제거된 0의 총 개수를 `[반복 횟수, 제거된 0의 개수]` 형태로 리턴하는 함수를 완성하라.

### 접근
- `s`가 `"1"`이 될 때까지 `while` 반복
- 매 반복마다 `count(s.begin(), s.end(), '0')`으로 0의 개수를 세서 누적
- `count(s.begin(), s.end(), '1')`로 남은 1의 개수(=제거 후 길이)를 구하고, 이를 `toBinary()`로 2진수 문자열로 변환해 `s`에 대입
- `toBinary(int n)`: `n % 2`를 반복해서 문자로 이어붙인 뒤(`'0' + n % 2`), 뒤집어서(`reverse`) 리턴 — 나머지 연산으로 직접 2진 변환

### 시간복잡도
O(n log n) 근처 — 문자열 길이가 매 반복마다 log 스케일로 줄어듦

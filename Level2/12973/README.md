## 짝지어 제거하기

- 문제번호: 12973
- 난이도: Level 2
- 유형: 스택

### 문제
알파벳 소문자로 이루어진 문자열 s에서, 같은 알파벳이 붙어 있는 짝을 찾아 지운다. 지운 뒤 생긴 새로운 짝도 계속 지운다. 모든 문자를 제거할 수 있으면 1, 그렇지 않으면 0을 반환하는 함수를 완성하라. (1 ≤ |s| ≤ 1,000,000)

### 접근
스택(`vector<char>`)에 문자를 하나씩 넣으면서:
- 스택이 비어있지 않고 맨 위 문자가 현재 문자와 같으면 → `pop_back()` (짝 제거)
- 아니면 → `push_back()` (쌓기)

`pop`으로 사라진 자리에서 새로 인접하게 된 문자들도 다음 반복에서 자연스럽게 비교되므로, 연쇄 제거가 한 번의 스캔으로 처리된다. 스캔이 끝났을 때 스택이 비어 있으면 전부 짝지어졌다는 뜻 → 1, 남아 있으면 → 0.

`s.erase()`로 문자열에서 직접 지워가며 처음부터 다시 스캔하는 방식은 O(n²)이라 시간 초과가 난다.

### 시간복잡도
O(n) — 각 문자를 최대 한 번 push, 한 번 pop

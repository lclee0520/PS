## 예상 대진표

- 문제번호: 12985
- 난이도: Level 2
- 유형: 구현 / 수학

### 문제
N명이 토너먼트로 게임을 진행한다. 1번↔2번, 3번↔4번, ... 씩 겨루고, 이긴 사람은 다음 라운드에서 다시 1번부터 번호를 배정받는다. 처음 라운드에서 A번을 가진 참가자가 경쟁자 B번 참가자와 몇 번째 라운드에서 만나는지 반환하는 함수를 완성하라. (A, B는 서로 만나기 전까지 항상 이긴다고 가정)

- N: 2¹ 이상 2²⁰ 이하 (2의 지수승, 부전승 없음)
- A, B: N 이하의 자연수, A ≠ B

### 입출력 예
| N | A | B | answer |
|---|---|---|--------|
| 8 | 4 | 7 | 3 |

### 접근
매 라운드가 끝나면 `(1,2)`, `(3,4)`, `(5,6)`, ... 쌍이 각각 다음 라운드에서 `1`, `2`, `3`, ... 번으로 새로 배정된다. 이 매핑은 **`x = (x + 1) / 2`** 로 표현된다 (정수 나눗셈으로 올림 효과).

- `a`, `b` 가 같아질 때까지 매 라운드마다 `a = (a+1)/2`, `b = (b+1)/2` 로 갱신하며 라운드 수를 센다.
- `a == b` 가 되는 순간이 두 사람이 처음 만나는 라운드.

> 주의: 그냥 `a /= 2` (일반 정수 나눗셈)를 쓰면 안 된다. 짝수는 `x/2`와 `(x+1)/2`가 우연히 같아서 맞는 것처럼 보이지만(`4/2=2=(4+1)/2`), **홀수는 값이 하나씩 작게 나와** 틀린다(`3/2=1`이지만 `(3+1)/2=2`가 맞는 값). 예를 들어 `solution(8, 3, 4)`(1라운드에서 바로 만남, 정답 1)를 `a/=2`로 풀면 `4`라는 틀린 답이 나온다.

### 검산 (N=8, A=4, B=7)
| 라운드 | a | b | 만남? |
|--------|---|---|-------|
| 시작 | 4 | 7 | ✗ |
| 1 | 2 | 4 | ✗ |
| 2 | 1 | 2 | ✗ |
| 3 | 1 | 1 | ✓ |

정답 `3`.

### 시간복잡도
O(log N) — 매 라운드 번호가 절반씩 줄어듦

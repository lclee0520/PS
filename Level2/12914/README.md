## 멀리 뛰기

- 문제번호: 12914
- 난이도: Level 2
- 유형: DP, 행렬 거듭제곱

### 문제
효진이는 한 번에 1칸 또는 2칸을 뛸 수 있다. `n`칸을 이동하는 방법의 수를 `1234567`로 나눈 나머지를 리턴하는 함수를 완성하라. (1 ≤ n ≤ 2000)

### 접근
방법의 수를 `ways(n)`이라 하면 마지막 뜀이 1칸이었는지 2칸이었는지로 나뉘므로:
```
ways(n) = ways(n-1) + ways(n-2)
ways(1) = 1, ways(2) = 2
```
즉 피보나치 수열이다 (표준 피보나치를 한 칸 민 형태, `ways(n) = fib(n+1)`).

처음엔 재귀로 경우의 수를 잎(leaf) 단위로 하나씩 세었는데, 같은 부분 문제를 지수적으로 다시 계산해서(O(1.618ⁿ)) `n`이 45만 되어도 10초가 걸려 시간 초과가 났다. 값을 직접 누적하는 DP로 바꿔야 한다.

**행렬 거듭제곱 O(log n)**:
```
| 1  1 |ⁿ     | fib(n+1)  fib(n)   |
| 1  0 |   =  | fib(n)    fib(n-1) |
```
`M = {{1,1},{1,0}}`를 분할정복으로 `n`제곱하면(`M → M² → M⁴ ...`, 지수를 이진수로 쪼개 필요한 자리만 곱함) 곱셈 약 11번으로 끝난다. 결과 행렬의 `[0][0]`이 `fib(n+1) = ways(n)`.

- 2×2 행렬 곱은 각 원소 계산마다 `% 1234567` (오버플로 방지, 원소가 `long long`이어야 함 — `1234566²` ≈ 1.5e12는 int 범위 초과)
- 거듭제곱은 단위행렬 `{{1,0},{0,1}}`에서 시작

반복문 DP(변수 2개로 O(n))로도 충분하지만, 여기서는 행렬 거듭제곱으로 풀었다.

### 시간복잡도
O(log n) — 행렬 거듭제곱

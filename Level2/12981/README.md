## 영어 끝말잇기

- 문제번호: 12981
- 난이도: Level 2
- 유형: 구현 / 해시(선형탐색)

### 문제
n명이 순서대로 돌아가며(1번 → 2번 → ... → n번 → 1번 → ...) 끝말잇기를 한다. 앞사람이 말한 단어의 마지막 글자로 시작해야 하고, 이전에 등장한 단어는 다시 쓸 수 없다. 규칙을 어기는 사람이 처음 나오는 시점의 `[번호, 그 사람의 몇 번째 차례]`를 반환하는 함수를 완성하라. 탈락자가 없으면 `[0, 0]`을 반환한다.

(2 ≤ n ≤ 10, n ≤ words 길이 ≤ 100, 2 ≤ 단어 길이 ≤ 50, 소문자만)

### 입출력 예
| n | words | result |
|---|-------|--------|
| 3 | ["tank","kick","know","wheel","land","dream","mother","robot","tank"] | [3,3] |
| 5 | (탈락자 없는 예시) | [0,0] |
| 2 | ["hello","one","even","never","now","world","draw"] | [1,3] |

### 접근
사람 번호·차례를 `i % n`, `i / n` 으로 바로 계산하는 대신, **카운터 두 개**(`count_times`, `count_turns`)를 돌려가며 추적한다.

- `count_times` : n에서 시작해 매 단어마다 1씩 감소. 0이 되면(한 바퀴를 다 돎) 다시 n으로 리셋하고 `count_turns`(차례)를 1 늘린다.
- 이번 단어를 말한 사람 번호는 `person = n - count_times` (감소시킨 직후 값 기준).

각 단어 `words[i]` 마다 두 가지를 검사한다.
1. **끝말이 안 이어짐**: `i != 0` 이고 `words[i-1].back() != words[i].front()`
2. **중복 단어**: 지금까지 나온 단어를 담은 `vector<string> s` 안에 `words[i]` 가 이미 있는지 `find(s.begin(), s.end(), words[i])` 로 확인

둘 중 하나라도 걸리면 그 즉시 `{person, count_turns}` 를 반환한다. 걸리지 않으면 `s` 에 추가하고 계속 진행, 끝까지 안 걸리면 `{0, 0}`.

> `set` 대신 `vector` + `find` 를 썼기 때문에 중복 검사가 O(현재까지 나온 단어 수)의 선형 탐색이다. `words` 최대 100개라 전체 O(words²)이어도 문제없다.

### 검산 (n = 3, words = ["tank","kick","know","wheel","land","dream","mother","robot","tank"])
- i=0~7 까지는 끝말도 이어지고 중복도 없음
- i=8, `words[8] = "tank"` → `s` 안에 이미 있음(중복) → 이때 `count_times`는 1바퀴(3개)씩 3번 돈 뒤 8번째라 `person = 3`, `count_turns = 3`
- 결과 `[3, 3]`

### 시간복잡도
O(n²) — words 길이를 n이라 할 때, 매 단어마다 지금까지의 단어 목록을 선형 탐색

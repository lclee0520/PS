## 최솟값 만들기

- 문제번호: 12941
- 난이도: Level 2
- 유형: 그리디 (rearrangement inequality)

### 문제
자연수로 이루어진 두 배열 A, B가 주어질 때, A의 각 원소와 B의 각 원소를 하나씩 짝지어 곱한 뒤 모두 더한 값이 최소가 되도록 하는 값을 구하는 함수를 완성하라. (배열의 크기는 같고, 각 배열의 원소는 한 번씩만 사용)

### 접근
그리디하게 A,B를 오름차순으로 정렬한 뒤, A는 앞에서부터(`i`), B는 뒤에서부터(`j`) 반대 방향으로 훑으면서 `A[i] * B[j]`를 곱해 더하면 최솟값이 된다.
- 큰 값과 작은 값을 짝지어야 곱의 합이 최소가 된다 (rearrangement inequality)
- A, B 둘 다 오름차순으로 정렬한 뒤, `i`는 0부터 증가, `j`는 `B.size()-1`부터 감소시키면서 짝지으면 A는 오름차순, B는 사실상 내림차순으로 대응된다 (같은 인덱스끼리 곱하는 게 아니라 인덱스가 서로 반대로 움직임)

### 시간복잡도
O(n log n) — 정렬이 지배적

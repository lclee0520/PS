## 카펫

- 문제번호: 42842
- 난이도: Level 2
- 유형: 완전탐색 / 수학

### 문제
갈색(brown) 격자와 노란색(yellow) 격자의 개수가 주어진다. 카펫은 테두리 한 줄이 전부 갈색이고 안쪽이 전부 노란색인 직사각형이다. 카펫의 [가로, 세로] 크기를 배열로 반환하는 함수를 완성하라. (가로 ≥ 세로)

(brown: 8 ~ 5000, yellow: 1 ~ 2,000,000)

### 관계식
카펫의 가로를 `w`, 세로를 `h`라 하면:

| 값 | 식 |
|----|----|
| 전체 격자 수 | `w * h = brown + yellow` |
| 노란색 (안쪽 직사각형) | `(w - 2) * (h - 2) = yellow` |
| 갈색 (테두리 한 줄) | `w*h - (w-2)*(h-2) = 2*(w + h) - 4 = brown` |

### 접근
`total = brown + yellow` 는 `w * h` 이므로, 세로 `h` 는 `total` 의 **약수**여야 한다. 또 `w >= h` 조건 때문에 `h <= sqrt(total)`.

1. `h` 를 1부터 `h * h <= total` 인 동안 증가시킨다.
2. `total % h != 0` 이면 직사각형이 안 되므로 건너뛴다.
3. `w = total / h` (이렇게 두면 `h <= w` 가 자동 보장).
4. 테두리 갈색 수 `2*(w + h) - 4` 가 주어진 `brown` 과 같으면 그 `{w, h}` 가 정답. (문제에서 해는 유일)

작은 `h` 부터 확인하므로 처음 만나는 후보가 곧 답이고, 바로 반환하면 된다.

### 검산 (brown = 10, yellow = 2)
`total = 12`. 확인할 `h`: 1, 2, 3 (`3*3 = 9 <= 12`).

| h | w = 12/h | 갈색 `2*(w+h)-4` | brown(10)과 비교 |
|---|----------|------------------|------------------|
| 1 | 12 | 22 | ✗ |
| 2 | 6  | 12 | ✗ |
| 3 | 4  | 10 | ✓ → `[4, 3]` 반환 |

### 시간복잡도
O(√(brown + yellow)) — total의 약수 후보만 훑는다

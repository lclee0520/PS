## N개의 최소공배수

- 문제번호: 12953
- 난이도: Level 2
- 유형: 수학 (최대공약수/최소공배수)

### 문제
숫자를 담은 배열 `arr`이 주어질 때, `arr` 안에 있는 모든 숫자들의 최소공배수(LCM)를 리턴하는 함수를 완성하라.

### 접근
- 배열의 앞에서부터 두 개씩 최소공배수를 누적해 나간다: `lcm(lcm(arr[0], arr[1]), arr[2]) ...`
- `lcm(a, b)`는 내부적으로 `a * b / gcd(a, b)`로 계산되고, `gcd(a, b)`는 **유클리드 호제법**으로 구한다.
  - 유클리드 호제법: `gcd(a, b) = gcd(b, a % b)`를 `b`가 `0`이 될 때까지 반복 (그때 `a`가 최대공약수)
  - 예: `gcd(8, 14)` → `gcd(14, 8)` → `gcd(8, 6)` → `gcd(6, 2)` → `gcd(2, 0)` → `2`
- `<numeric>`(`bits/stdc++.h`에 포함)의 `std::gcd`, `std::lcm`이 이 방식으로 구현되어 있어서 직접 구현 없이 바로 사용
- `start`를 `arr[0]`, `arr[1]`의 lcm으로 초기화하고, 인덱스 `2`부터 끝까지 순회하며 `lcm(start, arr[i])`로 계속 누적

### 시간복잡도
O(n log(min(a,b))) — 유클리드 호제법 자체가 O(log(min(a,b))), 이걸 배열 길이만큼 반복

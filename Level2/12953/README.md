## N개의 최소공배수

- 문제번호: 12953
- 난이도: Level 2
- 유형: 수학 (최대공약수/최소공배수)

### 문제
숫자를 담은 배열 `arr`이 주어질 때, `arr` 안에 있는 모든 숫자들의 최소공배수(LCM, Least Common Multiple)를 리턴하는 함수를 완성하라.

### 최대공약수(GCD)와 최소공배수(LCM)란?
- **최대공약수(GCD)**: 두 수를 동시에 나눌 수 있는 가장 큰 수. 예를 들어 `8`과 `14`를 동시에 나눌 수 있는 수는 `1, 2`가 있는데, 가장 큰 건 `2` → `gcd(8, 14) = 2`
- **최소공배수(LCM)**: 두 수의 공통 배수 중 가장 작은 수. `8`의 배수(`8,16,24,...`)와 `14`의 배수(`14,28,42,56,...`)가 겹치는 가장 작은 값 → `lcm(8, 14) = 56`
- 둘은 이 공식으로 이어져 있다:
```
lcm(a, b) = a * b / gcd(a, b)
```
왜냐하면 `a * b`는 항상 `a`와 `b`의 공배수인데, 그 안에 `gcd(a,b)`만큼 "중복"이 끼어있어서 그만큼 나눠주면 가장 작은 공배수가 된다.

### GCD를 구하는 방법: 유클리드 호제법
두 수를 하나씩 나눠보면서 최대공약수를 찾는 건 느리다(`min(a,b)`번 시도해야 함). **유클리드 호제법**은 나머지 연산으로 훨씬 빠르게 구한다.

**원리**: `gcd(a, b) = gcd(b, a % b)`, `b`가 `0`이 될 때까지 반복하면 그때의 `a`가 최대공약수다.

**`gcd(48, 18)` 손으로 따라가기**:
```
gcd(48, 18) → 48 % 18 = 12  → gcd(18, 12)
gcd(18, 12) → 18 % 12 = 6   → gcd(12, 6)
gcd(12, 6)  → 12 % 6  = 0   → gcd(6, 0)
gcd(6, 0)   → b가 0이므로 종료, 답은 6
```

**코드로 구현하면(재귀)**:
```cpp
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

int lcm(int a, int b) {
    return a / gcd(a, b) * b;   // a*b가 오버플로 날 수 있어서 나누고 곱하는 순서 주의
}
```
(참고: `<numeric>`(`bits/stdc++.h`에 포함됨)에 `std::gcd`, `std::lcm`이 이미 이 방식으로 구현되어 있어서, C++17부터는 직접 안 짜고 바로 갖다 써도 된다.)

### 이 문제에서의 접근
배열이 2개가 아니라 **N개**니까, 앞에서부터 순서대로 두 개씩 LCM을 누적해 나간다.
```
lcm(lcm(lcm(arr[0], arr[1]), arr[2]), arr[3]) ...
```
LCM은 교환법칙·결합법칙이 성립하므로(순서를 바꿔서 묶어도 결과가 같음), 이렇게 앞에서부터 순서대로 누적해도 전체 배열의 최소공배수가 정확히 나온다.

```cpp
int solution(vector<int> arr) {
    int start = lcm(arr[0], arr[1]);
    for (int i = 2; i < arr.size(); i++) {
        start = lcm(start, arr[i]);
    }
    return start;
}
```

**예제로 확인 `arr = [2, 6, 8, 14]`**:
```
start = lcm(2, 6)  = 6
start = lcm(6, 8)  = 24
start = lcm(24, 14) = 168   ← 정답
```

### 시간복잡도
O(n · log(min(a,b))) — 유클리드 호제법 한 번이 O(log(min(a,b)))이고, 이걸 배열 길이(n)만큼 반복한다.

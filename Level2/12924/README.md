## 숫자의 표현

- 문제번호: 12924
- 난이도: Level 2
- 유형: 수학 / 투 포인터

### 문제
자연수 n이 주어질 때, n을 연속한 자연수들의 합으로 표현하는 방법의 수를 구하는 함수를 완성하라. (n 자기 자신도 하나의 방법으로 센다. 1 ≤ n ≤ 15000)

### 접근
투 포인터(슬라이딩 윈도우). 구간 `[left, right]`의 합 `sum`을 항상 유지하면서:
- `sum < n` → `right`를 늘려 창을 넓힌다 (`sum += ++right`)
- `sum > n` → `left`를 늘려 창을 좁힌다 (`sum -= left++`)
- `sum == n` → 방법 하나를 세고, `left`를 늘려 다음 경우를 탐색한다

`left`가 1부터 n까지 이동하므로 `[n, n]`(항 1개, n 자체)까지 모두 확인된다.
`sum`을 매번 다시 더하지 않고 증분으로만 갱신하는 것이 핵심.

> 참고: 답은 결국 **n의 홀수 약수 개수**와 같다.

### 시간복잡도
O(n) — `left`, `right` 각각 최대 n번만 증가

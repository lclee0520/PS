## 최적의 행렬 곱셈

- 문제번호: 12942
- 난이도: Level 3
- 유형: DP

### 문제
크기가 `a×b`인 행렬과 `b×c`인 행렬을 곱하면 `a×b×c`번의 곱셈 연산이 필요하다. 행렬 곱셈은 결합법칙이 성립하므로 어떤 순서로 곱해도 결과는 같지만, **곱하는 순서에 따라 필요한 곱셈 연산 횟수가 달라진다.**

각 행렬의 크기가 담긴 2차원 배열 `matrix_sizes`가 주어질 때, 모든 행렬을 곱하기 위한 **최소 곱셈 연산 횟수**를 반환하라.

- 행렬 개수: 3 이상 200 이하
- 각 행렬의 행, 열 크기: 200 이하 자연수
- 주어진 순서대로 곱할 수 있는 행렬만 입력으로 주어진다 (앞 행렬의 열 = 뒤 행렬의 행)

### 입출력 예
| matrix_sizes | result |
|--------------|--------|
| `[[5, 3], [3, 10], [10, 6]]` | 270 |

- `(A×B)×C` = 5×3×10 + 5×10×6 = 150 + 300 = 450
- `A×(B×C)` = 3×10×6 + 5×3×6 = 180 + 90 = **270**

## 정수 삼각형

- 문제번호: 43105
- 난이도: Level 3
- 유형: DP

### 문제
삼각형의 꼭대기에서 바닥까지 이어지는 경로 중, 거쳐간 숫자의 합이 가장 큰 경우를 찾는다. 아래 칸으로 이동할 때는 대각선 방향으로 한 칸 왼쪽 또는 오른쪽으로만 이동 가능하다. 삼각형의 정보가 담긴 배열 `triangle`이 주어질 때, 거쳐간 숫자의 합의 **최댓값**을 반환하는 함수를 완성하라.

- 삼각형의 높이는 1 이상 500 이하
- 삼각형을 이루는 숫자는 0 이상 9,999 이하의 정수

### 입출력 예
| triangle | result |
|----------|--------|
| [[7],[3,8],[8,1,0],[2,7,4,4],[4,5,2,6,5]] | 30 |

### 접근
`triangle` 과 같은 모양의 DP 배열 `v`를 만들어, `v[i][j]` = "꼭대기에서 `(i, j)` 칸까지 오는 최대 경로 합"으로 위에서 아래로 채운다.

- `v[0] = {triangle[0][0]}` (첫 줄은 그대로)
- `i >= 1` 일 때, `(i, j)` 칸의 부모는 바로 위 줄의 `(i-1, j-1)` 과 `(i-1, j)`:
  - `j == 0` (맨 왼쪽) → 부모가 `(i-1, 0)` 하나뿐: `v[i][j] = v[i-1][j] + triangle[i][j]`
  - `j == i` (맨 오른쪽) → 부모가 `(i-1, j-1)` 하나뿐: `v[i][j] = v[i-1][j-1] + triangle[i][j]`
  - 그 외 → 두 부모 중 큰 쪽 선택: `v[i][j] = max(v[i-1][j-1], v[i-1][j]) + triangle[i][j]`
- 다 채운 뒤, **마지막 줄** `v[n-1]` 중 최댓값이 답 (바닥의 어느 칸으로 끝나든 되므로 마지막 줄 전체를 봐야 함)

`vector<vector<int>> v(n)` 로 바깥 크기만 잡고 각 줄은 `v[i].resize(...)` 로 채워도 되고, `v = triangle` 로 통째로 복사해 모양을 그대로 가져와도 된다.

### 자주 하는 실수
- `v[0][0] = ...` 처럼 `[0]`을 두 번 인덱싱하면, `v[0]`이 아직 크기 없는 빈 벡터일 때 범위 밖 접근으로 **크래시**한다. `v[0] = {값}` 처럼 `v[0]` 전체를 새 벡터로 교체해야 함.
- `v[i][j] = ...` 를 `v[i][j] == ...` 로 잘못 쓰면(대입 대신 비교) 컴파일은 되지만 값이 저장되지 않는다.
- `*max_element(...)`: `max_element`는 값이 아니라 반복자(iterator)를 반환하므로 실제 값을 꺼내려면 `*`로 역참조해야 한다.
- `auto answer;` 처럼 초기값 없이 `auto`만 선언하면 타입을 추론할 수 없어 컴파일 에러. `auto`는 선언과 동시에 초기화해야 한다.

### 시간복잡도
O(n²) — n = 삼각형 높이(최대 500), 전체 칸 수만큼 한 번씩 계산

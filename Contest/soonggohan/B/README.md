# B — 문자열 조건 판별

- **문제**: 길이 정보 `n`과 문자열 `t`가 주어진다. `t`가 조건을 만족하면 `hi`, 아니면 `bye`를 출력한다.
- **풀이**: `O`의 개수(`cntO`)만 세어 두 경우를 확인한다.
  - 전부 `O`인 경우 (`cntO == len`)
  - `O`가 하나도 없고 길이가 4인 경우 (`cntO == 0 && len == 4`)
  - 둘 중 하나면 `hi`, 아니면 `bye`.
- **시간복잡도**: O(N)

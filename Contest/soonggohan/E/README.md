# E — 원형 배열 회전과 조회

- **문제**: `1..N`이 순서대로 놓인 원형 배열에 쿼리 `Q`개가 들어온다.
  - `1 x`: 왼쪽으로 `x`칸 회전
  - `2 x`: 오른쪽으로 `x`칸 회전
  - `3 x`: 현재 배열의 `x`번째 원소 출력
- **풀이**: 배열을 실제로 돌리면 쿼리마다 O(N)이라 느리다. 대신 시작 위치 `pin`만 관리한다.
  - 1번: `pin = (pin - x + N) % N`
  - 2번: `pin = (pin + x) % N`
  - 3번: `v[(pin + x - 1) % N]` 출력
- **시간복잡도**: O(N + Q)

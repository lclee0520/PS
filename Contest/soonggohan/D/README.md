# D — 구간 양 끝 문자 검사

- **문제**: `M`, `T`로 이루어진 문자열 `s`와 쿼리 `Q`개가 주어진다. 쿼리는 구간 `[l, r]`이며, 가능하면 `YES`, 불가능하면 `NO`를 출력한다.
- **풀이**: 구간 안쪽은 볼 필요 없이 양 끝만 확인하면 된다. `s[l]`이 `T`이거나 `s[r]`이 `M`이면 `NO`, 그렇지 않으면 `YES`. 쿼리마다 O(1)로 답한다.
- **시간복잡도**: O(N + Q)

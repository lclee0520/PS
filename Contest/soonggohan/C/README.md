# C — 이진 문자열을 십진수로 변환

- **문제**: `O`와 `I`로 이루어진 문자열이 주어질 때, 이를 이진수로 해석한 값을 구한다. 테스트케이스가 여러 개다.
- **풀이**: `O`는 0, `I`는 1로 바꿔 배열에 담는다. 맨 앞에 `1`을 하나 붙인 뒤, 뒤에서부터 2의 거듭제곱(1, 2, 4, …)을 곱해 더한다. 문자열이 길어질 수 있어 `long long`을 쓴다.
- **시간복잡도**: O(T · N)
